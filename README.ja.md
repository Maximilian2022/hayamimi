## ✨ Hayamimi Live とは？

**Hayamimi Live（早耳 Live）** は、VTuber、ゲーム実況者、ストリーマーのために開発された、**CPU だけで動くリアルタイム音声認識＆多言語同時翻訳 字幕システム**です。

高価なグラフィックボード（GPU）や有料のクラウド API は一切不要。  
ごく一般的なノート PC の CPU だけで、**喋り終えた瞬間に約 0.1 秒（100ms）で文字が確定**し、OBS Studio の配信画面へ美しい字幕をリアルタイムに届けます。

```
[ あなたの声 (マイク) ]
       │
       ▼ (CPUのみで超高速ローカル推論)
┌──────────────────────────────────────────────┐
│  Hayamimi Live Engine                        │
│  ├─ 日本語高精度認識 (ReazonSpeech INT8)     │
│  └─ リアルタイム多言語翻訳 (FuguMT & M2M-100)│
└──────────────────────────────────────────────┘
       │
       ▼ (OBS Studio ブラウザソース / 透過オーバーレイ)
┌──────────────────────────────────────────────┐
│  配信画面字幕:                               │
│  「こんにちは！今日も配信やっていくよ！」    │
│  ↳ [EN] Hello! Today we are streaming!       │
│  ↳ [ZH] 你好！今天也要开始直播啦！           │
└──────────────────────────────────────────────┘
```

## 🔥 主な特長

### 1. 喋った瞬間に字幕が出る（超低遅延・高精度）
- 発話中からドラフト字幕がリアルタイムに表示され、**話し終えるとわずか約 100ms で確定**。
- 日本語最高峰の精度を誇る ReazonSpeech INT8 モデルを内包し、滑らかな文字起こしを実現します。

### 2. リアルタイム多言語同時翻訳（海外リスナー大歓迎）
- 自分が話した日本語を、**英語、中国語（簡体/繁体）、韓国語、スペイン語、フランス語、ドイツ語**などへ同時並行でリアルタイム翻訳。
- 海外の視聴者ともリアルタイムにコミュニケーションが取れます。

### 3. 配信が映える多彩なフォント ＆ エフェクト
- **人気 Google Fonts を大量内包**: 丸ゴシック（M PLUS Rounded）、手書き丸文字（Hachi Maru Pop）、レトロドット（DotGothic16）、躍動コミック（Reggae One）、毛筆（Yuji Boku）、洋画風欧文（Montserrat）など。
- **メイン字幕と翻訳字幕を個別にカスタマイズ**:
  - メインは大きめの白文字＋黒枠、英語翻訳は小さめの水色文字、中国語翻訳は黄色文字など、自由自在。
- **リッチなエフェクト**: クッキリ際立つ「通常縁取り」、テレビテロップ風の「二重枠」、サイバーに光る「ネオン発光」をワンクリック選択。

### 4. GPU 不要・外部通信ゼロ（完全無料・安全）
- 音声認識も翻訳も、すべてお使いの PC の内部だけで完結します。
- 外部クラウドへの送信は 1 バイトも行わず、利用料やAPIトークン制限も一切ありません。

## 🚀 かんたん 3 ステップ利用開始

### ステップ 1: アプリを起動する
フォルダ内の **`start.bat`** をダブルクリックします。  
画面右下にモダンランチャーが立ち上がったら、**「▶ 音声認識を開始する」** を押すだけで準備完了です。

### ステップ 2: OBS に字幕を追加する
1. OBS Studio の「ソース」で **`+`** ──▶ **「ブラウザ」** を追加します。
2. URL に **`http://localhost:8833/`** と入力し、幅 `1920` / 高さ `1080` に設定します。
3. これだけで、配信画面に背景透過の字幕が重なります。

### ステップ 3: ブラウザで話す ＆ デザインを調整する
ブラウザで **`http://localhost:8833/mic`** を開くと、Web マイク入力画面が表示されます。  
ここでマイクをオンにして喋れば字幕が出現し、画面上でフォントや色、翻訳言語を自由にポチポチ変更できます。
